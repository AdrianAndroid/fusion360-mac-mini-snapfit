## 恢复方法

在 Fusion 360 中使用“文件 → 打开 → 从我的电脑打开”，选择需要的 `.f3d` 文件。若只需最终模型，选择步骤6；若需要返工某个阶段，选择对应步骤的检查点。

## 后续保存规则

1. 每一步建模完成并通过尺寸或体积自检后，立即导出独立 `.f3d`。
2. 检查导出文件确实存在且大小非零。
3. 保存同步骤 PNG 截图，并追加 `MAC_MINI_CASE_MODELING_LOG.md`。
4. 新步骤使用新文件名，不覆盖旧检查点。
5. 不自动导出 STL；需要切片文件时另行等待指令。
